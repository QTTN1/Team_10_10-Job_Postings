\section{Project Title and Description}

\subsection{JobGuard – An AI-Powered Job Posting Fraud Detection Platform}

JobGuard will build a data engineering and machine learning platform that continuously 
collects job postings, cleans and standardizes them, and adds them to an existing dataset for analysis.

The project will classify postings as potentially legitimate or fraudulent while also exploring how 
current, outdated, and inconsistent job information can affect the analysis.

The main emphasis will be on building a reproducible data pipeline that could later be extended to 
support near-real-time job monitoring and personalized job recommendations.

\section{Preliminary Data Sources}

We will combine existing labeled job-posting datasets, such as Internship Scam Detection 
DatasetLinks to an external site on Kaggle and Ghost Job Detection DatasetLinks to an external site 
on Hugging Face, with a small number of newly collected public job postings.

We may also collect postings from up to three public sources, such as company career pages or publicly 
accessible job-posting pages, and store both the raw and cleaned versions.

These new records will be standardized and appended to the existing dataset to demonstrate ingestion from multiple sources.

\section{Preliminary Architecture and Steps}

The pipeline will follow:

Public Job Sources $\rightarrow$ Raw Data Ingestion $\rightarrow$ Cleaning and Standardization $\rightarrow$ Structured Tables 
$\rightarrow$ PostgreSQL/pgvector $\rightarrow$ ML Classification $\rightarrow$ RAG/LLM Explanation
$\rightarrow$ FastAPI $\rightarrow$ React Application.

Each source will be processed separately to handle differences in fields, formatting, and 
outdated information before the data is combined into a common schema. Apache Airflow will orchestrate 
the workflow so that new postings can be collected, cleaned, validated, and added to the dataset repeatedly.

\section{Relevant Tech Stack}

The project will use Python, pgvector, and SQL for ingestion, transformation, storage, and querying.

Scikit-learn/NLP models, OpenAI API, sentence embeddings, and vector similarity search will 
support fraud classification and RAG-based explanations.

Apache Airflow, FastAPI, React, Docker, GitHub Actions, and pytest will support orchestration, 
application development, reproducibility, CI/CD, and testing.
